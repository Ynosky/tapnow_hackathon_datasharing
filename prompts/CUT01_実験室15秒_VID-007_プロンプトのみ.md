【生成設定】
Kling 4.0、Omni Reference、15秒。
白い研究所でのユナの問診を、14のショットをハードカットでつないだ1本の映像として1回で生成する。短いショットを静かに重ねる編集で、各ショットの構図ははっきり読めるように保つ。全編を同じ研究所内で撮影する。登場人物はユナだけ。ミオと温室はこの映像に登場させない。
ショットの流れは「アップ → 目元のドアップ → 肌の寄り → 真横 → 手元 → 床すれすれ → 一人称視点 → モニターの映り込み → 天井の根 → スピーカー → 監視カメラ → 真上からの俯瞰 → 背後の肩越し → 引き」。寄りから始めてさらに寄り、さまざまな視点を挟み、最後に初めて部屋全体を見せる。

【人物】
ユナの顔、黒髪のボブと前髪、右頬の小さなほくろ、衣装、体格を人物シートどおりに全編で維持する。身長170cmの細身の少女として、椅子との比率を自然にする。研究者は成人女性の画面外の声のみ。人物シートの白背景、パネル配置、見本のポーズは映像にしない。
全編でユナに、さりげない人間らしい動きを残す。完全に静止させず、呼吸に合わせた胸と肩のごく小さな上下、首と頭のわずかな揺れ、ときどきの小さな嚥下、指先の微かな動き、前髪や髪の毛先の微かな揺れを自然に続ける。動きは小さく不規則で、意識的な演技やポーズに見せない。
【目の状態】
ユナの目は、虹彩の模様と瞳孔の輪郭がはっきり見えるように映す。左右の瞳孔の開き方が違い、本人の右目の瞳孔は小さく収縮し、左目の瞳孔は大きく開いている。左右の差は目元に寄ると分かる程度に、自然な範囲で保つ。まぶたは重く、上まぶたが瞳の上部にわずかにかかり、今にも落ちそうな半ば閉じかけた状態を保つ。ときどき、ゆっくりと重い瞬きをし、まぶたが一瞬落ちかけてから、また重たげに持ち上がる。

【空間】
白い研究所の環境シートの室内をそのまま使う。地下の窓のない密閉室で、床は5m×5m、天井高3m。黄ばんだオフホワイトの壁紙、継ぎ目の浮きと天井近くの水染み、湿ったベージュのカーペット、吊り天井と蛍光灯パネル4枚、換気口とスピーカー。部屋の中央に椅子1脚。正面から見て右の壁際に小さな机と古い箱型モニター（画面は暗い）。天井の隅の継ぎ目から、細く短い淡色の根が1本だけ垂れている。
窓、天窓、ドーム、空、外の眺望、植物の葉、追加の家具、ほかの人物は加えない。環境シートの文字、寸法線、図面、複数パネルは再現しない。

【映像の雰囲気と照明】
このシーンの照明と質感は以下を優先する。全体を暗めに、重く湿った空気感で撮る。明るく均一な画にしない。
光源は天井の古い蛍光灯だけ。くすんだ黄緑色の弱い光で、部屋の隅、壁の上部、カーペットの奥へ向かって暗く沈む。影は柔らかく、ユナの眼窩、首の下、椅子の下に深い影が落ちる。白い部分も白飛びさせず、くすんだ灰色がかったオフホワイトに抑える。空気中にごく薄い埃が漂う。
ユナを部屋の光の中に溶け込ませる。ユナの顔、髪、白い服にも同じ黄緑色の蛍光灯の色かぶりと同じ明るさを当て、服は真っ白に光らせない。椅子とカーペットの接地面に接地影を出す。人物だけのライティング、輪郭を縁取る光、美肌の補正、背景からの切り抜きのような見え方にしない。人物と背景に同じ粒子、同じ柔らかさ、同じ露出を適用する。
古い家庭用ビデオカメラのような控えめなソフトさ、低いコントラストの暗部、薄いノイズ。

【蛍光灯のちらつき】
蛍光灯は古く、普段は低く唸りながらわずかに不安定に点いている。時々、4枚のうち1枚だけが寿命の近い管のように不規則にちらつく。数回すばやく瞬いて少し暗くなり、安定器のジジッという音とともに元に戻る。ほかのパネルは点いたまま。部屋は真っ暗にならず、点滅のリズムは規則的にしない。ちらつきに合わせて、ユナの顔と壁の明るさもほんのわずかに揺れる。演出的なストロボや全灯の点滅にしない。ユナはちらつきにまったく反応しない。

【0–2.8秒｜ショット1：アップ】
ユナの胸から上のアップ。座ったユナの目線よりわずかに上からの固定カメラ、ほぼ正面。パン、ズーム、手ブレなし。
ユナはうなだれている。首の力が抜けて頭が前に落ち、前髪が目元に少しかかる。視線は下へ落ち、目の焦点がまったく合っていない。まぶたは重く落ちかけている。暗く無機質な真顔。唇は軽く閉じる。呼吸に合わせて肩がごく小さく上下し、頭がわずかに揺れる。
0–0.8秒：蛍光灯の唸り、空調音、浅い呼吸だけ。
0.8–2.6秒：画面外の落ち着いた女性研究者が、ナレーションのように平坦で単調な日本語で「具合はどうですか」。ユナは答えず、口を動かさない。

【2.8–4.0秒｜ショット2：目元のドアップ】
ユナの両目を収める極端なクローズアップ。85mmマクロ相当、正面寄りの固定カメラ。前髪の影が目元にかかるが、両目の虹彩の模様と瞳孔の輪郭ははっきり見える。本人の右目の瞳孔は小さく、左目の瞳孔は大きく開き、左右の違いがこのショットで分かる。上まぶたは重く垂れ、瞳の上部にわずかにかかっている。視線は何にも焦点を結んでいない。
3.1秒頃、両眼だけが本人の右へ、唐突でぎこちなく動いて止まる。頭は追従しない。
3.5–3.8秒、瞳の表面に細い赤い光が一瞬映り、消える。角膜上の小さな反射として見せ、虹彩そのものは発光させない。

【4.0–4.8秒｜ショット3：肌の寄り】
ユナの右頬から首筋への極端な寄り。右頬の小さなほくろ、肌の産毛と毛穴、首筋でかすかに打つ脈。肌は蛍光灯の黄緑色の光をかぶり、くすんでいる。ユナが小さく唾を飲み込み、喉がわずかに動く。

【4.8–5.6秒｜ショット4：真横】
ユナの真横からのミディアムショット。座った腰の高さの固定カメラ。うなだれた頭、丸まった背中、膝の上の手、椅子の輪郭。背景は暗く沈む黄ばんだ壁。呼吸で背中と肩がわずかに上下する。
5.1秒頃、天井の蛍光灯の1枚が数回不規則にちらつき、壁とユナの横顔の明るさがわずかに揺れて戻る。ユナは反応しない。

【5.6–6.3秒｜ショット5：手元】
腿の上に置かれたユナの両手のクローズアップ。指は力なく揃い、白い服の布地が膝の上でわずかに皺をつくる。人差し指だけがごく小さく一度ぴくりと動く。手指の本数と関節を保つ。微かな衣擦れ。

【6.3–7.0秒｜ショット6：床すれすれ】
湿ったカーペットすれすれの高さからのローアングル。椅子の脚と、床についたユナの足先。カーペットの暗い湿りのシミが手前に広がる。片足のつま先がごくわずかにカーペットを擦る。

【7.0–8.4秒｜ショット7：ユナの一人称視点】
ユナの目から見た一人称視点。手持ちのような不安定なカメラ。視界は少しぼやけ、焦点が合いそうで合わずに揺れ続ける。視線が定まらず、膝の上の自分の手、カーペット、黄ばんだ壁、天井の蛍光灯へとさまよう。頭がぐらりと回るように視界がゆっくり傾き、めまいのようにわずかに回転する。蛍光灯を見上げた瞬間に光がにじみ、視界の端が暗くかすむ。音はこもり、自分の呼吸だけが近い。

【8.4–9.1秒｜ショット8：モニターの映り込み】

【9.1–9.7秒｜ショット9：天井の根】

【9.7–10.5秒｜ショット10：スピーカー】

9.8秒から、同じ女性研究者が同じ単調な声で「どうされましたか」と話し始める。声はこのスピーカーから鳴っているように、わずかにこもって聞こえる。

【10.5–11.3秒｜ショット11：監視カメラ】
天井の隅の監視カメラの映像。部屋を高い角から見下ろす広角の固定画角で、椅子にうなだれて座るユナが小さく映る。低画質の監視映像らしく、粗いノイズ、わずかな走査線、にじみ、暗部のつぶれ、やや歪んだ広角。画面上の文字、時刻表示、録画マークは入れない。
研究者の「どうされましたか」は11.2秒頃に言い終わる。ユナは顔を上げない。

【11.3–12.0秒｜ショット12：真上からの俯瞰】
天井から真下を見下ろす真上の俯瞰。うなだれたユナの頭頂部と黒髪のつむじ、肩、膝、椅子、その周りのカーペットのシミ。標本を見下ろすような冷たい構図。沈黙。

【12.0–12.6秒｜ショット13：背後の肩越し】
ユナの背後、肩越しのショット。黒髪の後頭部と肩がぼやけて手前にあり、その先には何もない正面の黄ばんだ壁だけが見える。誰に話しかけられているのか分からない空っぽの空間。沈黙。

【12.6–15秒｜ショット14：引き】
初めて部屋全体を見せる引きのショット。環境シートの主画と同じ構図。座ったユナの目線の高さから、真正面の固定カメラ、35mm相当、ほぼ左右対称。椅子に座るユナを画面中央に小さく置き、奥の壁、天井の蛍光灯パネル、右の壁際の机とモニター、湿ったカーペットが入る。暗い部屋の中にユナが孤立して見える。
12.6–13.0秒：ユナがゆっくりと顔をわずかに上げ、小さく息を吸う。焦点は合わず、まぶたは重いまま。
13.0–14.7秒：ユナが暗いトーンの小さな声で「動揺していないです」。ほとんど抑揚をつけず、最小限の口の動きで、自然な日本語を話す。語尾を上げない。研究者は重ねて話さない。
14.7–15秒：ユナは口を閉じ、ゆっくり一度重い瞬きをする。奥の蛍光灯の1枚が短くちらついて落ち着き、その画面のまま終える。

【音・制約】
BGMなし。劇伴、歌唱、子守歌、旋律、音楽的ドローンなし。
音は指定した日本語の台詞、微かな呼吸、空調音、蛍光灯の低い唸りとちらつき時の安定器の小さな音、自然な衣擦れだけ。ショットが変わっても空調音と蛍光灯の唸りは途切れずに続く（一人称視点の間だけ、こもって遠く聞こえる）。

全編で研究所の空間、照明の色、ユナの外見と衣装を維持する。グリッチ、記憶映像、指切り、キメラ、温室への場面転換、ガラスの破砕を入れない。
