## 継続保存のルール

- 会話で確定した設定や変更は、その都度 `story.md` に反映し、最新の内容を一か所で読める状態にします。更新日と出典も記録します。
- 未確定の案は確定事項と区別します。過去の版は Git の履歴から参照できます。
- 生成・提示した画像プロンプトは `image_prompts.md`、動画プロンプトは `video_prompts.md` に全文を追記します。修正時も旧版を残します。
- 画像プロンプトには、`image_prompts.md` に保存済みの必須共通冒頭文を毎回全文含めます。
- 受領した過去のプロンプトは当時の全文を改変せず保存します。共通冒頭文ルールは新規作成・改訂時に適用します。
- プロンプトの作成と画像・動画の生成実行は、別の状態として記録します。
- 日付は日本時間で記録します。
